# 第一阶段采集协议（v0.1）

## 时间窗

使用最近 10 个完整出版年：2016-01-01 至 2025-12-31。2026 年尚未结束，不纳入主样本；后续可单列增量。

## 期刊范围

30 刊采用“领域影响力 + 子方向覆盖”而非单纯 JIF 排名。纳入标准：主要发表大气科学、气象学、气候动力学、大气化学、气溶胶、边界层、遥感/观测、数值模式或水文气象研究；优先 JCR Meteorology & Atmospheric Sciences 高分区期刊及 AMS/AGU/EGU/RMetS 等核心学会期刊。

`data/journals.csv` 是候选清单。正式版本需补录当年 JCR 类别、分区或其他权威依据，并保留核验日期与来源。

## 每刊候选与抽样

1. 以 OpenAlex 来源 ID/ISSN 获取 2016–2025 年论文，按 `cited_by_count` 降序抓取最多 1,000 篇候选。
2. 排除勘误、社论、新闻、书评；保留 research article 与 review，并记录文献类型。
3. 从 OpenAlex topics/concepts 提取主题。以引用排名为基础，使用主题新颖度加权的贪心抽样选 100 篇：
   - 引用排名保证“高被引”；
   - 对尚未充分覆盖的主题给予奖励，避免单一热门方向占满配额；
   - 至少保留各刊引用最高的核心论文。
4. DOI 去重；跨刊重复或更名期刊需要人工审计。

## 全文取得

下载优先级：出版社/OpenAlex 标记的合法 OA PDF → 机构订阅出版社 PDF → 记录为 `manual_required`。每次下载记录 URL、时间、HTTP/页面结果、文件大小和 SHA-256。不得把受版权保护的 PDF 提交到公开 GitHub 仓库。

## 局限

引用数对较早年份有累积优势，且数据库覆盖存在差异。最终清单应同时保存 WoS Times Cited 与 OpenAlex cited_by_count；若二者冲突，不静默覆盖。
