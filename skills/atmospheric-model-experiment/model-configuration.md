# Model and experiment configuration

Record model name and version; code changes; grid and effective resolution; vertical coordinate; time step; domain; initialization; lateral and lower boundary conditions; data assimilation; forcing/scenario; parameterizations; land/ocean state; spin-up; ensemble perturbations; nesting; post-processing; and verification period.

Separate four claims:

1. forecast performance on a declared sample;
2. process representation or physical fidelity;
3. sensitivity to a controlled configuration change;
4. projection behavior under a forcing scenario.

Evidence for one does not automatically establish the others. A higher resolution is not automatically a fairer or better model; check tuning, effective resolution, conservation, computational budget, and verification scale.
