# Atmospheric Manuscript Writer

Write publication-ready scientific prose while preserving the boundary between verified literature, performed methods, observed results, and interpretation.

## Preconditions

Inventory what is available: target article/journal or audience, research question, verified evidence records, actual data and methods, completed analyses, figures/tables, author-approved results, limitations, and citation style. If results are absent, write a protocol, outline, or placeholder-based draft—not a completed results paper.

## Workflow

1. Build a claim map linking each planned statement to literature evidence, methods, a result/figure/table, or clearly labeled interpretation.
2. Define the manuscript contribution without asserting novelty until a current literature search supports it.
3. Draft an outline with one function per section and a logical progression from gap to question, methods, results, interpretation, limits, and implications.
4. Write the introduction from broad problem to precise gap and objective. Prefer primary evidence for substantive claims and reviews for field framing.
5. Write methods so a qualified researcher can reproduce the study: data versions, domain/period, variables/units, QC, processing, models, statistics, validation, software/configuration, and deviations from a protocol.
6. Write results from actual outputs in the order of the research questions. Report denominators, effect direction/magnitude, uncertainty, and figure/table references; keep interpretation limited.
7. In discussion, compare like with like, explain convergence and conflict, distinguish evidence from mechanism hypotheses, address robustness and limitations, and constrain generalization.
8. Make abstract and conclusion consistent with the main evidence; do not introduce new results or stronger causal language.
9. Audit terminology, units, acronyms, coordinate/time bases, dataset/product versions, references, figure/table numbering, and internal numerical consistency.
10. Return a provenance note identifying author-supplied facts, source-backed statements, unresolved placeholders, and passages needing domain review.

## Output

- Manuscript or requested section
- Claim/source/result map
- Explicit placeholders and unresolved questions
- Citation and internal-consistency audit
- Scope, uncertainty, and author-review notes

## Quality gates

Never create sample sizes, statistics, experiments, citations, data availability, ethics statements, or results. Do not imitate a living author's style or reproduce copyrighted passages. Do not optimize rhetoric by removing necessary qualifications.

## Example

`Use atmospheric-manuscript-writer to draft the Methods and Discussion from my verified evidence table, analysis notebook outputs, and six figures; leave explicit placeholders for missing configuration details.`
